# شعار فز و العب

فكرة الشعار: نقاط الحروف صارت أشكال اللعب. نقطة **ف** دائرة صفراء، ونقطة **ز** مربع أحمر، ونقطة **ب** مثلث أزرق.

## الملفات (`out/`)
| الملف | الاستخدام |
|---|---|
| `logo.svg` / `logo.png` | الشعار الكامل (عربي + FIZZ & PLAY) على خلفية فاتحة. PNG بخلفية شفافة |
| `logo-dark.svg` / `logo-dark.png` | نفسه للخلفيات الغامقة |
| `logo-on-cream.png` / `logo-on-navy.png` | الشعار مع خلفيته (للسوشال ميديا والعروض) |
| `wordmark*.svg/png` | الكلمة العربية بس |
| `icon.svg` / `icon-1024.png` | أيقونة التطبيق (حرف ف) |
| `profile-1080.png` | صورة البروفايل لإنستقرام وواتساب |

ملفات SVG فكتور، تكبر لأي حجم بدون ما تخرب. **للمطبعة أرسل ملف SVG**.

الألوان: كحلي `#1B2A4A`، كريمي `#FFFBF2`، أصفر `#FFC23D`، أحمر `#F2604F`، أزرق `#0A7F96`.

إعادة البناء: `cd brand && npm install && node build.js`. الأمر يحدّث أيقونات التطبيق في `app/assets` وأيقونة الموقع كمان.
